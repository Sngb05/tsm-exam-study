# TSM&O 시험 대비

https://sngb05.github.io/tsm-exam-study/

TSM&O 2026 강의자료 Part 1~4와 주차관리(교체법 포함) 전체를 정리한 학습 사이트입니다. 데스크톱, 아이패드, 아이폰에서 모두 볼 수 있고 홈 화면에 추가하면 앱처럼 열립니다.

- **요약노트**: 14개 장, 슬라이드 순서대로 정리. 수업 필기(빨간 펜 상자)와 시험 포인트(노란 상자) 표시. 필기 숨기기, 핵심어 가리기 모드
- **퀴즈**: 객관식·OX·단답·서술 206문제. 범위·유형·문제 수 선택, 오답 다시 풀기
- **플래시카드**: 용어 111장, 모르는 카드만 다시 보기
- **숫자 암기표**: 시험에 나올 만한 수치 105개, 가리고 외우기
- **검색**: `/` 또는 상단 돋보기

학습 기록은 각 기기의 브라우저에만 저장됩니다. 원본 슬라이드와 PDF는 포함하지 않았습니다.

## 내용 고치기

빌드 과정이 없습니다. `data/p1.js`~`data/p4.js`(노트·퀴즈·카드·숫자)를 고친 뒤, `index.html`과 `sw.js`의 `?v=` 숫자를 하나 올리고 커밋·푸시하면 1분쯤 뒤 사이트에 반영됩니다.
